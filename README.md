# 누리고 (Nurigo)

## 청년 전통시장 유입 프로젝트

전통시장은 지역의 음식과 사람, 이야기가 가장 가까이 모이는 공간입니다. 하지만 청년층에게는 일부러 찾아갈 이유와 머무르며 둘러볼 계기가 충분하지 않을 때가 많습니다.

누리고는 전통시장을 단순히 물건을 사는 장소가 아니라, 걸으며 발견하고 함께 참여하는 지역 경험으로 바꾸려는 프로젝트입니다. 시장에 들어서면 보상과 이야기가 놓인 지점을 만나고, 자연스럽게 골목과 가게를 탐색하게 됩니다.

첫 단계에서는 대전 지역의 여러 전통시장을 중심으로 이 경험을 만들고 검증합니다.

시장 구역 안에서 500보 걷기, 특정 가게에서 상품 구매하기, 친구와 함께 방문하기 같은 활동은 하나의 확장 가능한 경험이 됩니다. 참여에 대한 보상도 온누리상품권 포인트부터 지역 홍보대사의 친필 사인 기념품까지, 시장과 지역의 특성에 맞게 다양해질 수 있습니다. 이 예시는 확정된 기능이나 보상 정책이 아니라 누리고가 열어 두고 있는 가능성입니다.

누리고가 만들고 싶은 것은 일회성 할인이 아니라 다시 방문할 이유입니다. 청년에게는 새로운 동네 경험을, 상인에게는 새로운 관계와 유입을, 지역에는 오래 이어지는 활기를 연결하는 것이 이 프로젝트의 방향입니다.

## 개발 현황

- `mobile/`: Expo SDK 57 기반 Android 지도·Polygon 편집 및 PostGIS draft 등록 앱
- `apps/api/`: Spring Boot 4.1 기반 시장 경계 draft·검수·조회 API
- `docs/`: 아키텍처, 시장 데이터 규칙, 개발 가이드와 로드맵

로컬 실행과 필요한 환경변수는 [개발 가이드](./docs/DEVELOPMENT.md), 현재 구현 범위는 [프로젝트 상태](./docs/PROJECT_STATUS.md)를 참고하세요.
